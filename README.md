# โครงการจัดการไฟล์ JSON

## ภาพรวม
โครงการนี้ถูกออกแบบมาเพื่อช่วยในการจัดการและปรับปรุงไฟล์ JSON โดยอัตโนมัติ โดยมีฟังก์ชันการทำงานดังนี้:

1. เพิ่มคีย์ใหม่ (`image`) ลงในไฟล์ JSON หลายไฟล์พร้อมกัน
2. อัปเดตไฟล์ JSON ที่มีอยู่ด้วยฟิลด์ที่กำหนดเอง
3. บันทึกการทำงานและการเปลี่ยนแปลงเพื่อการติดตามและแก้ไขปัญหา

โปรเจกต์นี้จะประมวลผลไฟล์ JSON ที่อยู่ในโฟลเดอร์ `data/input` และบันทึกไฟล์ที่ได้รับการปรับปรุงลงในโฟลเดอร์ `data/output`

---

## โครงสร้างโปรเจกต์

```
.
├── README.md         # เอกสารประกอบโครงการ
├── data              # โฟลเดอร์สำหรับเก็บไฟล์ JSON
│   ├── input         # โฟลเดอร์สำหรับไฟล์ JSON ต้นฉบับ
│   └── output        # โฟลเดอร์สำหรับไฟล์ JSON ที่ปรับปรุงแล้ว
├── logs              # โฟลเดอร์สำหรับไฟล์ log และข้อมูลการรีวิว
├── requirements.txt  # รายการ dependencies ที่จำเป็นสำหรับโปรเจกต์
└── scripts           # สคริปต์ Python สำหรับจัดการไฟล์ JSON
    ├── add_image_key.py  # สคริปต์สำหรับเพิ่มคีย์ 'image' ให้กับไฟล์ JSON
    └── update_data.py    # สคริปต์สำหรับอัปเดตข้อมูลในไฟล์ JSON
```

---

## ฟีเจอร์

### 1. **เพิ่มคีย์ Image**
สคริปต์: `scripts/add_image_key.py`

- สแกนไฟล์ JSON ทั้งหมดในโฟลเดอร์ `data/input`
- เพิ่มคีย์ `image` ที่ไม่ซ้ำให้กับทุก object ในฟิลด์ `rating_schema`
- บันทึกไฟล์ที่ปรับปรุงแล้วลงในโฟลเดอร์ `data/output`
- บันทึกผลลัพธ์ใน `logs/script_run.log`
- เก็บข้อมูลคีย์ที่เพิ่มลงใน `logs/review_counts.json`

### 2. **อัปเดตข้อมูล**
สคริปต์: `scripts/update_data.py`

- อัปเดตไฟล์ JSON ที่ระบุในโฟลเดอร์ `data/input`
- เพิ่มฟิลด์ที่กำหนดเอง (เช่น `updated: true`) ลงในไฟล์ JSON
- บันทึกไฟล์ที่อัปเดตแล้วลงในโฟลเดอร์ `data/output`
- บันทึกผลการทำงานใน `logs/script_run.log`

## วิธีการใช้งาน

### ข้อกำหนดเบื้องต้น
- Python 3.7+
- ติดตั้ง dependencies:
  ```bash
  pip install -r requirements.txt
  ```

### การตั้งค่าโฟลเดอร์
ตรวจสอบให้แน่ใจว่าโฟลเดอร์ต่อไปนี้มีอยู่:

- `data/input` (สำหรับไฟล์ JSON ต้นฉบับ)
- `data/output` (สำหรับไฟล์ JSON ที่ปรับปรุงแล้ว)
- `logs` (สำหรับไฟล์ log และการติดตามรีวิว)

### การรันสคริปต์

#### เพิ่มคีย์ Image ให้กับไฟล์ JSON
รันคำสั่งนี้เพื่อเพิ่มคีย์ `image` ให้กับไฟล์ JSON ทั้งหมดในโฟลเดอร์ input:
```bash
python scripts/add_image_key.py
```

#### อัปเดตข้อมูลในไฟล์ JSON
รันคำสั่งนี้เพื่ออัปเดตไฟล์ JSON ที่ระบุ:
```bash
python scripts/update_data.py
```

## ตัวอย่าง

### ไฟล์ JSON ต้นฉบับ
ไฟล์ต้นฉบับ: `data/input/example.json`
```json
{
  "rating_schema": [
    { "id": 1, "rating": 5 },
    { "id": 2, "rating": 3 }
  ]
}
```

### ไฟล์ JSON ที่ปรับปรุงแล้ว (หลังจากรัน `add_image_key.py`)
ไฟล์ที่ปรับปรุงแล้ว: `data/output/example.json`
```json
{
  "rating_schema": [
    { "id": 1, "rating": 5, "image": "example_review0" },
    { "id": 2, "rating": 3, "image": "example_review1" }
  ]
}
```

### ตัวอย่าง Log
ไฟล์ Log: `logs/script_run.log`
```plaintext
[2024-12-15 12:00:00] SUCCESS: Added 'image' key to 2 items in example.json.
```

## Logs และการติดตาม

### Log File
- ตำแหน่ง: `logs/script_run.log`
- บันทึกการทำงานของสคริปต์อย่างละเอียด รวมถึงความสำเร็จและข้อผิดพลาด

### Review Counts
- ตำแหน่ง: `logs/review_counts.json`
- เก็บข้อมูลการแมปชื่อไฟล์ JSON กับรายการคีย์ `image` ที่เพิ่มเข้าไป
